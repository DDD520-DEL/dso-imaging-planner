# 深空天文摄影规划工作台

一个前后端一体的深空摄影规划工具：光学采样与视场、曝光与信噪比估算、目标可见性、跟踪精度校核，
配一个可增删的自定义目标库。

项目**不依赖任何第三方 npm 包**，全部使用 Node 内置能力（`node:http`、`node:fs`、`node:test`），
clone 后即可直接运行和测试，也不需要数据库。

## 运行

```bash
npm start
```

打开 `http://localhost:5175`。页面右上角会显示接口在线状态，填好参数点「开始规划」会一次性调用四类计算接口。
端口可通过环境变量覆盖，例如 `PORT=8080 npm start`。

## 测试

```bash
npm test
```

测试分五层：

- `test/optics.test.js`：像素尺度、传感器画幅、视场角、焦比、道斯/衍射极限、采样分级
- `test/exposure.test.js`：天光通量、单帧与叠加信噪比、天空背景主导曝光、饱和时间、目标信噪比反解
- `test/visibility.test.js`：中天高度、可观测时长（含恒显与不可见）、天文夜、午夜高度、月相
- `test/tracking.test.js`：星点 FWHM 合成、跟踪分级、极轴漂移率与允许极轴误差反解
- `test/api.test.js`：启动真实 HTTP 服务，验证健康检查、首页与样式、四类计算接口、目标库增删查重、错误处理与路径越界

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 服务健康检查 |
| GET | `/api/targets` | 返回内置目标与自定义目标 |
| POST | `/api/targets` | 新增自定义目标，body 为 `name`/`raHours`/`decDeg`/`magnitude`/`sizeArcmin`/`category` |
| DELETE | `/api/targets/:id` | 删除自定义目标；内置目标不可删除 |
| POST | `/api/optics/report` | 光学采样与视场计算 |
| POST | `/api/exposure/estimate` | 曝光与信噪比估算 |
| POST | `/api/visibility/plan` | 目标可见性规划 |
| POST | `/api/tracking/check` | 跟踪精度校核 |

四类计算接口的请求体与页面输入一一对应，参数越界或缺字段返回 `400`，响应体形如 `{ "error": "参数「焦距（mm）」不能小于 50，当前为 10" }`。

## 计算模型与口径

这套模型用于横向比较配置与曝光参数，结论按下述口径复现：

- **像素尺度**：`206264.806 × 像元尺寸(mm) ÷ 焦距(mm)`，单位 ″/px；视场角按 `2·atan(画幅 ÷ 2f)` 计算。
- **采样判定**：像素尺度与视宁度之比落在 `1/3 ~ 1/2` 判为「接近理想」，小于 `1/3` 为「过采样」，大于 `1/2` 为「欠采样」。
- **衍射极限**：`1.22λ/D`，默认参考波长 550 nm；道斯极限取 `116 ÷ 口径(mm)`。
- **像素天光通量**：以 21.5 mag/arcsec²、口径 100 mm、1.5 ″/px、透过率 0.8、量子效率 0.6 时约 8.5 e-/s/px 标定的相对模型，输出正比于口径面积、像素天区面积与亮度的 `10^(-0.4Δmag)`。
- **信噪比**：单帧 `S/√(S + D·t + R²)`，N 帧叠加按信号 `N·S`、方差 `N·(S + D·t + R²)` 合成；天空背景主导曝光取「天光信号达到读出噪声方差 10 倍」的时长。
- **可见性**：中天高度 `90 − |纬度 − 赤纬|`；可观测时长由最低可用高度角反解时角窗口；天文夜按太阳高度 −18° 近似。
- **午夜高度**：以太阳反照点赤经作为午夜中天赤经的近似，再由时角求目标高度。
- **月相**：以 2000-01-06 18:14 UTC 的新月为起点，按 29.530588853 天的朔望月周期计算月龄与照亮比例，不引入观测者地理经纬度。
- **跟踪校核**：星点 FWHM 由视宁度与跟踪误差的平方和合成（σ→FWHM 系数 2.355）；极轴偏差 `θ` 引起的赤纬漂移率按 `15°/h × sinθ` 近似，并按单帧漂移不超过 1 像素反解允许的极轴误差。

## 目标库

内置 10 个常见深空目标（M31、M42、M45、M51、M81、M101、M13、M8、NGC 7000、IC 1396），只读；
自定义目标通过界面或 `POST /api/targets` 写入 `data/targets.json`，删除后立即从列表移除。
目标库里的「用于可见性」按钮会把赤经赤纬填进左侧可见性参数。

目标记录字段：`name`（必填，≤40 字）、`raHours`（0–24）、`decDeg`（−90–90）、`magnitude`（可选）、`sizeArcmin`（可选）、`category`（可选）。

## 环境要求

- Node.js ≥ 18（开发与验证使用 Node 24）
- 无需数据库、无需第三方依赖
